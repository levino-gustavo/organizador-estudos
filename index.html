Como usar o StudyFlow

Cadastre uma tarefa, selecione uma matéria e escolha a prioridade.

Use a busca para encontrar tarefas pelo título ou pela matéria.

Os filtros permitem visualizar todas as tarefas, apenas pendentes ou concluídas.

Marque a caixa de uma tarefa quando terminar o estudo correspondente.

O painel de progresso acompanha as tarefas concluídas.

O timer ajuda a separar o tempo de foco das pausas.

As anotações são salvas automaticamente neste navegador.

O botão de exportação gera um arquivo JSON com os dados do aplicativo.

O tema pode ser alternado entre claro e escuro.

Os dados são armazenados localmente usando localStorage.

Perguntas frequentes

Onde ficam minhas tarefas?

As tarefas ficam salvas no armazenamento local deste navegador.

Posso fechar a página?

Sim. Os dados persistem neste navegador, salvo se os dados do site forem apagados.

Como começo o timer?

Escolha a duração e clique em Iniciar foco.

Como pauso o timer?

Clique no botão Pausar enquanto a contagem estiver ativa.

Posso editar uma tarefa?

Use o botão Editar no cartão da tarefa para alterar seu título.

Como removo uma tarefa?

Use o botão Excluir no cartão e confirme a ação.

O que faz Exportar dados?

Baixa um arquivo JSON com tarefas, notas e estatísticas.

O que acontece no modo escuro?

A interface troca suas cores para reduzir o brilho da tela.

A busca diferencia maiúsculas?

Não. A busca ignora diferenças entre maiúsculas e minúsculas.

Como vejo tarefas concluídas?

Selecione o filtro Concluídas na barra de filtros.

O timer registra foco?

Ao concluir um bloco, o tempo escolhido é somado aos minutos de foco.

Como limpo as anotações?

Clique em Limpar notas e confirme a ação.
